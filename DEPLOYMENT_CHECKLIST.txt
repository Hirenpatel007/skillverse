QUICK DEPLOY STEPS:
-------------------

1. PUSH TO GITHUB:
   git init
   git add .
   git commit -m "SkillVerse platform"
   git remote add origin https://github.com/YOUR_USERNAME/skillverse.git
   git push -u origin main

2. CREATE RENDER ACCOUNT:
   https://render.com

3. NEW WEB SERVICE:
   - Connect GitHub repo
   - Build: ./build.sh
   - Start: gunicorn skillverse.wsgi:application

4. ADD ENVIRONMENT VARIABLES:
   SECRET_KEY = (generate)
   DEBUG = False
   ALLOWED_HOSTS = .onrender.com

5. CREATE POSTGRESQL:
   - New PostgreSQL database
   - Copy DATABASE_URL to web service

6. DEPLOY:
   - Click "Create Web Service"
   - Wait 5-10 minutes
   - Live at: https://skillverse.onrender.com
